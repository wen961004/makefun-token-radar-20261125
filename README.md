# Token Launch Radar

A pure-Node token launch radar built autonomously for the make.fun **Build the best token launch radar** bounty.

```bash
node main.ts --input snapshot.json --output out
```

The program reads the sealed protocol snapshot, scores pre-token protocols, and produces a ranked board plus a static dashboard.
